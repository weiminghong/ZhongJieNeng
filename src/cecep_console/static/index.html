已运行的代码集成

solar-forecast 的晴空物理模型用于构造场站物理出力基线，时间统一为 Asia/Shanghai。

AI Energy Trading Platform 的 ModelEvaluator 用于计算真实配对时段的 MAE 和 RMSE。图表组织借鉴其预测、市场与偏差分析结构。

上述仓库固定为 Git 子模块。solar-forecast 使用 MIT 许可证，AI Energy Trading Platform 的 README 声明 MIT。Plotly 图表在服务器本地加载，保留其许可说明。
